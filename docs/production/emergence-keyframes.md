# Three emergence sequences: art-production briefs

Status: action proposals, no images produced. These implement the state language in [temple emergence](../temple-emergence.md). Keep a common coordinate origin and scene scale through disguise, separation and active form. Each source has a stationary seam/mount reference distinct from the actor's eventual foot origin.

## Ceramic sentinel

Source layers: intact jar, crack accents, lid/rim, unfolding body, movable shell pieces, resolved shards, funerary token. The jar used in the background and the first animation frame must be the same export, not redrawn approximations.

| Key | Image content | Readability and state |
| --- | --- | --- |
| C0 Disguised | Decorated grave vessel resting on plinth | Plausible scenery; silhouette and decoration establish identity |
| C1 Tell | One crack brightens with dust and a restrained lid tremor | Repeatable non-damaging cue; audible rattle complements visual |
| C2 Awakening | Rim parts; one articulated hand braces against its own vessel | Clear origin of force; no unrelated creature materializing |
| C3 Emergence peak | Body unfolds with fragments still attached as armor | Recognizable jar pattern survives across body segments |
| C4 Active settle | Feet/limbs find ground; shell mass settles | First stable combat pose; separate recovery before attack |
| C5 Resolved | Shell collapses into identifiable fragments around token | Same materials and decoration; one final reward state |

Commission C0/C3/C4 first as a continuity test. Then add C1/C2/C5 and required in-betweens. Emergence preview target is roughly 1.2–1.8 seconds after a distinct tell, entirely provisional. Attack timing stays a separate action; do not conceal damage in the last emergence frame.

## Painted procession guard

Source layers: wall substrate, fixed border, guard pigment, separation shadow, emerged body, remaining pigment/resolved decal. Preserve wall registration exactly. The guard must look like a painting acquiring volume, not a normal skeleton placed in front of a wall.

| Key | Image content | Readability and state |
| --- | --- | --- |
| M0 Disguised | Guard in a ceremonial procession band | Matches the mural's paint and flat perspective |
| M1 Tell | Eye/head or spear shifts within the painted panel | Change stays inside the artwork; no glow-only cue |
| M2 Awakening | Leading hand and weapon curl away like heavy paint | Seam shadow explains separation from stone |
| M3 Emergence peak | Upper body has volume, trailing leg remains flat | Deliberate mixed flat/solid anatomy is the signature |
| M4 Active settle | Foot touches world floor; paint tail retracts | Enough pause to read the new threat |
| M5 Resolved | Color drains/slides back into a damaged ceremonial figure | Avoid a generic dust puff that loses mural identity |

Keep the active silhouette related to M0, including weapon length and decorative rhythm. Frame-to-frame changes in dimensionality are intentional; arbitrary face or outfit changes are not. Offscreen procession movement can be atmosphere, but an activated damaging guard needs the encounter fairness rules.

## Burial-pit assembler

Source layers: pit rim/foreground lip, dark interior, reaching hands, passed bones, crawler/assembled body, settling bones. Use an explicit occlusion mask so the same pit lip naturally hides emerging lower limbs.

| Key | Image content | Readability and state |
| --- | --- | --- |
| B0 Disguised | Quiet burial trench with displaced dust | Read as a real architectural recess |
| B1 Tell | Fingertips press the lip; dust rolls toward the opening | Clear movement before body appears |
| B2 Awakening | Two hands pass a shoulder/skull upward | Assembly has physical causality and a readable focal point |
| B3 Emergence peak | Incomplete torso hauls itself over the rim | Crawling silhouette deliberately differs from sentinel |
| B4 Active settle | Arms support weight; mismatched skull is adjusted | One brief macabre/humorous beat may be held safely |
| B5 Resolved | Bones fall back through the same opening | Preserve pit occlusion and source ownership |

Avoid graphic anatomy; age, ritual and odd assembly carry the tone. The optional wrong-skull beat is authored once, not randomized identity drift across an entire frame family. A crawler must not change leg completeness between frames without an explicit assembly action.

## Shared handoff and acceptance

Provide isolated source layers, source origin, active actor origin, transfer marker, resolved-state export and a three-panel contact sheet (disguise/peak/settled). Metadata names source and encounter IDs but art never creates the actor twice. In the engine, inspect occupied-spawn delay, pause and interrupted emergence using the same assets. No seam jump at source-to-actor transfer; no unannounced damaging volume.
