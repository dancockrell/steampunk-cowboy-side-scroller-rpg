# Gameplay pillars

| Pillar | Required player experience | Design test |
| --- | --- | --- |
| Cowboy problem solving | Four tools combine in physical puzzles | A room asks for observation and combination, not just the matching weapon icon |
| Scenery has a life | Environmental transformation is anticipated and surprising | A tell can be noticed before the first damaging action |
| Readable physical play | Michael and hazards stay clear against ornate art | Play at target scale and dark-room lighting without debug outlines |
| Divine relationships have agency | Different choices reveal Michael's character | The goddess can disagree, defer or refuse; alliance is not purchased by a score |
| Handcrafted strange beauty | Temple culture, dead and humor share a world | Art, motion and dialogue retain place-specific identity |

## Input and feedback contract (provisional bindings)

| Action | Keyboard/mouse | Gamepad |
| --- | --- | --- |
| Move / jump | A/D or arrow keys, Space/W/Up | Left stick, south face |
| Aim / use equipped tool | Mouse, left click | Right stick, right trigger |
| Tool select | 1–4 | D-pad |
| Lasso release / cancel | Right click | Left trigger |
| Interact / reload | E / R | West / east face |
| Pause | Escape | Menu |

Bindings are a proposal, not configured gameplay. Offer remapping, aim assistance, toggle/hold aiming, readable subtitles, scalable dialogue text, reduced shake/flashes and tells that do not rely on color alone. Pause stops combat, emergence timers and aiming; dialogue in a safe shrine cannot leave Michael taking unseen damage.

## Failure and recovery

Early test targets: buffered jump and coyote time, both tunable after playtesting. No speculative exact jump distance is a production constraint. Falling/defeat returns to the latest checkpoint snapshot. Critical mechanisms can be reset; required ammunition and lasso anchors cannot be permanently exhausted. Save at safe shrine checkpoints, with encounter and puzzle states stored together. Never duplicate a reward after reload. An optional romance refusal must not block the temple's exit.
